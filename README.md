## Adding a New Policy

1. Add the policy HTML file under `shahforge-policies/` (e.g., `shahforge-policies/<app-name>.html`).
2. Add a new row to the **Policies** table above with the app name, policy type, package ID, version/scope, effective date, live GitHub Pages URL (`https://shahforge1.github.io/shahforge-policies/<app-name>.html`), and relative source link.

## Contact

For questions about any ShahForge policy, contact ShahForge via the developer contact email on the relevant app store listing or through GitHub ([`shahforge1`](https://github.com/shahforge1)).
